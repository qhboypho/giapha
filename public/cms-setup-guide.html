Hướng dẫn setup CMS gia phả cho khách mới

Quy trình này dùng khi clone base gia phả, tạo tài nguyên Cloudflare mới, import CMS package và deploy website cho một dòng họ/khách mới.

1. Chuẩn bị

  • Node.js 20+ và npm.
  • Git.
  • Tài khoản Cloudflare có quyền tạo Pages, D1, R2.
  • File CMS package .json của khách.
npx wrangler login

Cách dễ nhất cho khách mới là chạy Provision Wizard để sinh checklist và cấu hình Cloudflare theo tên khách.

npm run provision:wizard

2. Clone source

git clone https://github.com/qhboypho/giapha.git giapha-khach-a
cd giapha-khach-a
npm install
git checkout giapha-cms
git checkout -b customer/khach-a

3. Tạo Cloudflare resources

Tạo riêng cho mỗi khách:

  • Pages project, ví dụ giapha-khach-a.
  • D1 database, ví dụ giapha-khach-a-db.
  • R2 bucket, ví dụ giapha-khach-a-media.
npx wrangler d1 create giapha-khach-a-db
npx wrangler r2 bucket create giapha-khach-a-media

Nếu dùng AI nhận diện ảnh/PDF trong app, đặt secret mã hóa một lần cho Pages project:

npx wrangler pages secret put AI_CONFIG_SECRET --project-name giapha-khach-a

Sau bước này, admin có thể vào Cấu hình AI để chọn OpenAI/Gemini/Claude và lưu API key provider đã mã hóa trong D1.

4. Sửa wrangler.jsonc

Cập nhật name, database_name, database_id, bucket_name theo khách.

{
  "name": "giapha-khach-a",
  "d1_databases": [
    {
      "binding": "DB",
      "database_name": "giapha-khach-a-db",
      "database_id": "D1_DATABASE_ID_CUA_KHACH",
      "preview_database_id": "D1_DATABASE_ID_CUA_KHACH"
    }
  ],
  "r2_buckets": [
    {
      "binding": "MEDIA_BUCKET",
      "bucket_name": "giapha-khach-a-media",
      "preview_bucket_name": "giapha-khach-a-media-preview"
    }
  ]
}

5. Kiểm tra CMS package

Lệnh dry-run chỉ validate và sinh SQL, chưa ghi DB.

node scripts/cms-bootstrap.mjs --package=./data/khach-a-package.json

Nếu chạy qua npm trên Windows/PowerShell:

npm run cms:bootstrap -- -- --package=./data/khach-a-package.json

6. Import local để test

node scripts/cms-bootstrap.mjs --package=./data/khach-a-package.json --migrate --admin-password="mat-khau-admin-local" --yes

Lệnh này apply migrations, import config/members/history và tạo/update admin.

7. Chạy app local

npm run build
npm run dev:cf

Mở http://localhost:8788, đăng nhập bằng admin và mật khẩu vừa set.

8. Kiểm tra trong UI quản trị

  • Logo, tên dòng họ, hero, footer.
  • Cây gia phả, thành viên, người tiêu biểu.
  • Lịch giỗ và lịch sử dòng họ.
  • Mobile layout.
  • Export backup bằng Xuất gói CMS.
  • Nếu có ảnh lịch sử, export/import thêm Gói media R2.
  • Nếu khách đưa ảnh giấy gia phả, dùng Nhập gia phả bằng AI để copy prompt, paste JSON và preview.

9. Import production

node scripts/cms-bootstrap.mjs --package=./data/khach-a-package.json --remote --migrate --admin-password="mat-khau-admin-prod" --yes

Lệnh có --remote và --yes sẽ ghi vào D1 trên Cloudflare. Chỉ chạy sau khi local đã ổn.

10. Deploy Pages

npm run build
npx wrangler pages deploy ./dist --project-name giapha-khach-a

Sau khi deploy, gắn custom domain nếu khách có tên miền.

11. Bàn giao

  • URL website.
  • Tài khoản admin và mật khẩu tạm thời.
  • Yêu cầu khách đổi mật khẩu sau khi nhận.
  • Hướng dẫn export/import CMS package để backup/restore.

Ghi chú về ảnh R2

CMS package v1 chứa reference ảnh, còn binary ảnh được đóng gói riêng trong media package. Quy trình chuẩn là import CMS package trước để tạo dữ liệu, sau đó import gói media R2 để upload ảnh vào đúng key mà lịch sử dòng họ đang tham chiếu.
