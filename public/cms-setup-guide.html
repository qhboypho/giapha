Huong dan setup CMS gia pha cho khach moi

Quy trinh nay dung khi clone base gia pha, tao tai nguyen Cloudflare moi, import CMS package va deploy website cho mot dong ho/khach moi.

1. Chuan bi

  • Node.js 20+ va npm.
  • Git.
  • Tai khoan Cloudflare co quyen tao Pages, D1, R2.
  • File CMS package .json cua khach.
npx wrangler login

2. Clone source

git clone https://github.com/qhboypho/giapha.git giapha-khach-a
cd giapha-khach-a
npm install
git checkout giapha-cms
git checkout -b customer/khach-a

3. Tao Cloudflare resources

Tao rieng cho moi khach:

  • Pages project, vi du giapha-khach-a.
  • D1 database, vi du giapha-khach-a-db.
  • R2 bucket, vi du giapha-khach-a-media.
npx wrangler d1 create giapha-khach-a-db
npx wrangler r2 bucket create giapha-khach-a-media

4. Sua wrangler.jsonc

Cap nhat name, database_name, database_id, bucket_name theo khach.

{
  "name": "giapha-khach-a",
  "d1_databases": [
    {
      "binding": "DB",
      "database_name": "giapha-khach-a-db",
      "database_id": "D1_DATABASE_ID_CUA_KHACH",
      "preview_database_id": "D1_DATABASE_ID_CUA_KHACH"
    }
  ],
  "r2_buckets": [
    {
      "binding": "MEDIA_BUCKET",
      "bucket_name": "giapha-khach-a-media",
      "preview_bucket_name": "giapha-khach-a-media-preview"
    }
  ]
}

5. Kiem tra CMS package

Lenh dry-run chi validate va sinh SQL, chua ghi DB.

node scripts/cms-bootstrap.mjs --package=./data/khach-a-package.json

Neu chay qua npm tren Windows/PowerShell:

npm run cms:bootstrap -- -- --package=./data/khach-a-package.json

6. Import local de test

node scripts/cms-bootstrap.mjs --package=./data/khach-a-package.json --migrate --admin-password="mat-khau-admin-local" --yes

Lenh nay apply migrations, import config/members/history va tao/update admin.

7. Chay app local

npm run build
npm run dev:cf

Mo http://localhost:8788, dang nhap bang admin va mat khau vua set.

8. Kiem tra trong UI quan tri

  • Logo, ten dong ho, hero, footer.
  • Cay gia pha, thanh vien, nguoi tieu bieu.
  • Lich gio va lich su dong ho.
  • Mobile layout.
  • Export backup bang Xuat goi CMS.

9. Import production

node scripts/cms-bootstrap.mjs --package=./data/khach-a-package.json --remote --migrate --admin-password="mat-khau-admin-prod" --yes

Lenh co --remote va --yes se ghi vao D1 tren Cloudflare. Chi chay sau khi local da on.

10. Deploy Pages

npm run build
npx wrangler pages deploy ./dist --project-name giapha-khach-a

Sau khi deploy, gan custom domain neu khach co ten mien.

11. Ban giao

  • URL website.
  • Tai khoan admin va mat khau tam thoi.
  • Yeu cau khach doi mat khau sau khi nhan.
  • Huong dan export/import CMS package de backup/restore.

Ghi chu ve anh R2

CMS package v1 chua dong goi binary anh R2. Anh lich su nen upload qua UI sau khi setup, hoac xu ly media package o giai doan sau.
